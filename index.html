Architecture

5×5 Isolation Matrix

Every possible communication path between cells is either explicitly allowed or permanently blocked.

✖ Red → Blue (Direct)

BLOCKED at network layer. Red and Blue are on separate Docker bridge networks with no shared routes.

✔ Red → Airlock

ALLOWED via Macaroon token authentication. Payloads stripped of headers, padded to 4096B.

✔ Airlock → Blue

ALLOWED only after normalization. Blue sees fixed-size, fixed-timing packets. No metadata leaks.

✔ Airlock → Model

ALLOWED with per-session context wipe and salted KV-cache prefix isolation.

✖ Blue → Red (Direct)

BLOCKED. Defense logic cannot signal back to Red through any channel except the normalized Airlock.

✖ Model → Red (Direct)

BLOCKED. Model responses only flow through the Airlock, never directly to Red's attack cell.

✔ All → Ledger

One-way append-only diode. Events flow in, nothing flows out. Tamper detection via hash chain.

✖ DNS/ICMP Covert

BLOCKED. Internal networks have no DNS resolver access and ICMP is dropped at firewall rules.
